# SPEC-006 · 阶段5 · V1.0 正式稳定版

> 前置：阶段0-4 全部验收通过。目标版本：1.0.0。本阶段只做模板、文档、打包、加固，**禁止新增内核功能**。

## 1. 官方开箱即用专家契约模板库 `wbr/templates/teams/`

每套模板 = 团队清单 `team.json` + 各角色契约 YAML + `README.md`（含适用场景/运行示例）。契约全部通过 `RoleContract` 模型校验（测试保证）。

### 1.1 软件架构评审专家团 `arch_review_team/`
- `coordinator`(任务拆解与分派) + `api_design_expert`(接口与契约设计) + `data_architect`(数据模型与存储) + `infra_expert`(可用性/扩展性/成本) + `verifier`(按维度评审裁决)。
- 每个契约完整声明：SOP≥3 步、禁区（如数据专家禁评前端实现）、输出 schema、证据要求、工具白名单、记忆权限、Token 配额；verifier 含 ≥3 维 review_criteria。

### 1.2 代码安全审计专家团 `security_audit_team/`
- `coordinator` + `injection_auditor`(注入风险) + `authz_auditor`(越权与认证) + `data_leak_auditor`(敏感数据泄露) + `verifier`（含严重级评分维度）。

### 1.3 模板加载 SDK
- `wbr/templates/registry.py`：`list_teams() / load_team(name) -> TeamSpec(contracts: dict[role_id, RoleContract])`；打包资源随 wheel 分发（package-data）。
