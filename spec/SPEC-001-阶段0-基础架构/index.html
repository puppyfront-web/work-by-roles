    SPEC-001 · 阶段0 · 项目初始化与基础架构

    前置：SPEC-000。目标版本基线：0.1.0（架构基座，不含契约内核）

    1. 目标

    建立严格对齐三层架构的目录骨架与全局基础设施，使后续所有阶段在同一底座上开发。

    2. 交付内容

    2.1 目录结构与打包

    • 创建 SPEC-000 §5 规划的全部目录（空模块以最小占位实现）。
    • wbr/__init__.py：__version__ = "0.1.0"，禁止在阶段0 导出未实现符号。
    • pyproject.toml 更新：新增 wbr、wbr.* 到 packages；requires-python >= 3.10；依赖分层——基础依赖仅 pydantic>=2.5、pyyaml>=6.0；可选组 dev（pytest/pytest-cov/ruff/mypy）、langgraph、server（fastapi/uvicorn/httpx）、redis。
    • 存量 work_by_roles 打包配置与行为不受影响。

    2.2 全局异常体系 wbr/core/exceptions.py

    WBRError(code: str, message: str, *, trace_id: str|None, details: dict)
  ├─ ConfigError(E1001)
  ├─ ContractValidationError(E2001)      # 阶段1 起使用
  ├─ ContractCompileError(E2002)
  ├─ SchemaValidationError(E2003)
  ├─ ForbiddenViolationError(E2004)
  ├─ MemoryPermissionDeniedError(E3001)
  ├─ SecurityViolationError(E4001)
  ├─ TokenBudgetExceededError(E5001)
  ├─ OrchestrationError(E6001)
  ├─ HarnessError(E7001) / CacheError(E7002)
  ├─ AdapterError(E8001) / ToolPermissionDeniedError(E8002)
  └─ AppError(E9001)
to_dict() 可序列化；str(e) 含 [code] 前缀与 trace_id。

    2.3 全局 TraceID wbr/core/context.py

    • new_trace_id() -> str：wbr- + 32 位 hex（secrets）。
    • TraceContext：基于 contextvars 的当前 trace/span 携带；get_trace_id()/set_trace_id()/current_span_id()；跨线程执行需显式传递（编排层负责）。

    2.4 全局常量 wbr/core/constants.py

    • MEMORY_LAYERS 四层枚举：ROLE_STATIC / ROLE_SESSION / TASK_SCRATCH / GLOBAL_SHARED（阶段1 复用）。
    • 边界标记常量：EXTERNAL_CONTENT_OPEN/CLOSE、USER_INPUT_OPEN/CLOSE（阶段1/2 复用）。
    • 默认限额：DEFAULT_TOKEN_QUOTA=8000、AUDIT_BUS_MAX_QUEUE=10000。

    2.5 全局配置 wbr/core/config.py + wbr/config_loader.py

    • WBRConfig（Pydantic BaseModel，全部带默认值）： project_name="work-by-roles"、log_level="INFO"、audit_enabled=True、audit_bus_max_queue=10000、default_token_quota=8000、cache_enabled=True、cache_max_entries=4096、security_enabled=True、extra: dict。
    • WBRConfig.overlay(**kw) 返回新实例（不可变配置更新）。
    • wbr/config_loader.py：load_config(path: Path|None, overrides: dict|None) -> WBRConfig；YAML 文件可选、键白名单过滤、未知键忽略并告警；PyYAML 缺失时抛 ConfigError（D-15）。

    2.6 日志架构 wbr/core/logging.py

    • get_logger(name, *, trace_id=None) -> WBRAuditLogger：标准 logging 封装，每条记录附加 trace_id；
    • JsonFormatter：单行 JSON（ts/level/name/trace_id/message/extra）；
    • setup_logging(config: WBRConfig)：幂等初始化 root handler。

    2.7 审计事件总线 wbr/core/audit_bus.py

    • AuditEvent（阶段0 通用版：event_type: str, trace_id, payload: dict, ts）。
    • AuditBus：subscribe(fn) / publish(event) / publish_safe()——内部有界队列 + 独立派发，订阅者异常被捕获计数，绝不向调用方抛异常；dropped_count 属性暴露溢出丢弃数；bus.stats() 返回 published/dropped/subscribers。
    • 全局默认单例 default_bus()（可注入替换，便于测试隔离）。

    3. 非目标（禁止实现）

    契约模型、记忆、编排、安全、缓存、Harness、任何 Adapter/App 逻辑。
